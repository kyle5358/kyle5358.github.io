September 20, 2026

应用程序管理#

which#

$ which clear
/usr/bin/clear

yum#

安装和卸载系统中的工具

$ sudo yum -y install net-tools

控制台和输出管理#

cat#

文件内容输出

$ cat /etc/system-release
Red Hat enterprise Linux release 8.5

echo#

$ echo "hello world"
hello world

echo "hello world" > data.txt

export#

创建一个环境变量，并为其复制，然后将该环境变量或值导出到系统

$ export WEB_PAGE="http://www.redhat.com/en"
